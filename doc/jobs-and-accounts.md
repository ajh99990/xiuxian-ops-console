# 角色与脚本策略

角色配置保存在根目录的 `accounts.config.json`。

这个文件包含续玩编号、旧 token、脚本策略、启用状态、脚本参数和额外环境变量。它包含敏感信息，必须保持在 `.gitignore` 中。

## 模块

### `server/services/account-store.js`

负责：

- 读取 `accounts.config.json`
- 校验角色名和脚本白名单
- 标准化 `args` 和 `env`
- 写回配置
- 输出给 UI 前对续玩编号和 token 脱敏

### `server/services/job-manager.js`

负责：

- 按角色名启动脚本
- 停止单个脚本
- 启动全部启用任务
- 停止全部运行中任务
- 把续玩编号/token 注入子进程环境变量
- 把 stdout/stderr 写入日志服务

## 长跑脚本与定时任务的区别

长跑脚本适合持续循环的行为，例如：

- 综合优先
- 修炼闭关
- 福地/凶地探索

定时任务适合一次性动作，例如：

- 每天 00:05 所有角色普通修炼一次
- 每日领取一次奖励
- 定时统计角色状态

不要把“一天一次”的动作塞进长跑脚本循环里。它应该由 `server/scheduler/` 触发，并记录当天执行状态。
